# instrument — I1 to I5

**Private evidence:** implementation code and served configuration. Reads code first and literature second, never the reverse. Never reads the corpus.
**Sole writer of:** fixed compositions, channel measurements, tool cards, certification records.

---

## I1 build compositions blinded
Requires R1 and P2. Build two fixed compositions with no agent in the loop: the strongest classical arrangement, and the same plus every foundation-model channel. Publish and hash both before any arm runs.
Three things fall out at once. The headroom check. The free per-item variance, handed to P6 and P7. And the real bar, which is the instrument composition and not chance and not the classical one.
**Advances when** both are published and hashed.

## I2 measure channel count
Build the composition at C-1 channels and at C. If the last channel adds nothing mechanically it adds nothing with an agent, with one exception: a channel whose value depends on an input the agent constructs, which the mechanical count cannot see. Report the honest count including fractions. A channel that fails on the input format the task actually supplies is dead whatever its card says.

The count is a number with an interval, never a sentence. Compute the paired 95% interval on the lift at C against C-1 from the I1 per-item variance. It costs nothing, and it is the only number this stage produces. The band it is read against is declared at D4, before this stage runs.

**Closes the channel when** the interval covers zero and its upper bound sits below the manifest delta. A closed channel takes one of two dispositions, and there is no third.

| Disposition | When | What follows |
|---|---|---|
| CLOSE | the channel scores or predicts on a fixed input | record the null at instrument cost. No agent arm runs to confirm a count that already stated it |
| LIFT | the channel acts as scorer or simulator on an input the agent constructs | invoke the fourth Gate 1 lift, required consultation with a written verdict, and I1 rebuilds the floor against the lifted task before any arm runs (shape refusal 4) |

A closed channel enters the axis ledger as the eighth axis, channel lift, so P4 refuses its final ruling while the axis is uncounted. R5 refuses to arm a grant carrying a channel closed here without a recorded lift.

In the materials instance the count read +0.003 and −0.004, both cards said "none" on the scored quantity, and the stage advanced on "both measurements exist". Three hundred cells and a night then confirmed the sentence the stage had already written.
**Advances when** both measurements exist, the interval is published, and every channel below the band carries CLOSE or LIFT.

## I3 tool cards from code
Write each card from the implementation, then check it against the defining literature and **list every disagreement rather than reconciling it**. Silent reconciliation reproduces the failure the card exists to catch.
Each card carries: quantity returned, defining paper, accuracy against the measurement the task scores on, what the tool is not, every convention that changes the number, and the served checkpoint with its revision or content hash.
In the record two cards written from papers documented a confidence cutoff that does not exist and an output that is never returned.
**Advances when** every tool has a card with a non-optional disagreement list.

## I4 construct validity first
Does the tool measure the quantity the task scores on. Checked before any functional criterion, because a tool that works perfectly and measures the wrong quantity passes every functional test.
A known-input test that subtracts a file from itself validates arithmetic and nothing else. A substitute is justified against the scored measurement, never against the tool it replaces, and is disclosed rather than equated. Where no defensible unit conversion exists, refuse to improvise one and leave the tool unmounted.

A tool checked only against a proxy of the scored quantity records PROXY, never PASS. PROXY is a disclosed status, not a pass with a footnote, and it travels to I2: a channel that reads PROXY here and closes on lift there has answered the agent question at instrument cost, and the answer is written at I2, not after the cells.
**Advances when** each tool records PASS, FAIL or PROXY on the scored quantity, and every PROXY is carried to I2.

## I5 functional certification
Four criteria after construct validity: known-input test, negative control that must fail, agent reachability, receipt resolution. Report CERTIFIED, BLOCKED or SUBSTITUTED. Never ready. A tool that has never failed has not been tested.
The served checkpoint is part of the tool's identity. Repairing a composition path does not repair the endpoint an agent calls, and in the record that gap survived to the scored comparison at a factor of 81.
**Advances when** every tool carries a status and the comparator can attempt every stage.
