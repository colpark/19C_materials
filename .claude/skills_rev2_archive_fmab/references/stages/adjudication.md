# adjudication — A1 to A4

**Private evidence:** labels and blind prediction files. Never reads design rationale, traces or code.
**Sole writer of:** preregistration ledger, score record.
**Cost:** zero model calls. This module never closes a candidate. It reports, with the resolution limit attached.

---

## A1 preregister as records
Every preregistered element is a record with a current value and an amendment chain. Reports read the current value rather than restating it, so drift becomes impossible rather than detectable.
Prose preregistration is the failure mode. In the record metric primacy was fixed by amendment then silently reverted, and the two orderings disagreed in sign on the same data.
An item is burned when a scored element changes in response to what that item showed, not merely because it ran. A stale freeze is superseded and re-registered, never paid for in items. **Returns any item to the pool** unless a scored element changed in response to it.
**Advances when** metric order, chance baseline, coverage rule, repair budget and label protocol are all records, and the item ledger states which items are burned and why.

## A2 hash blind files
Every arm writes a blind prediction file. Hash all of them before any label opens.
**Advances when** every hash is recorded.

## A3 score once, paired
Requires I5, R4 and R7.
Arm means on different denominators are not a comparison. Score paired. An unpaired table understates the arm that produced no answer on the items where the floor did best.
Invalid answers are coverage failures, never zeros. Wire the precision-only extraction path into the scorer itself and not only into the smoke test. In the record an arm read as zero of ten while nine of its ten answers carried valid unique selections.
Score process metrics beside the outcome, with their own denominators: evaluation depth as distinct categories rather than call count, explicit rejection, candidates considered, handling of a weak tool return. Receipt validity is not evidence relevance, and categories reusing one receipt are one channel.
**Advances when** every arm has a score or a stated coverage failure.

## A4 report with chance and MDE
Requires P7 and R8.
Print the decision metric with its chance baseline, never the ranking metric alone. In the record a strong ranking statistic sat beside a near-chance decision three separate times.
Print MDE beside every effect, read from the power record. Refuse a directional claim at or below it. Say what the null does establish, which is that no large effect is hiding.
Mark any recovery that happened after labels opened as post-hoc and never call it prospective.
**Advances when** a claim or a no-claim is written with both baselines beside it.
